# ADR-003: Strategy is versioned and machine-readable

## Context

Decision logic cannot be audited if market, ICP, buyer, offer, or motion assumptions exist only in
unversioned prose.

## Decision

Decision-relevant strategy will be machine-readable, versioned, evidence-labeled, and explicitly
promoted.

## Consequences

Decisions reference the strategy version used. Strategy changes create new versions rather than
silently rewriting history.

## Status

Accepted
