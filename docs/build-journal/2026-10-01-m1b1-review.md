# M1B.1 Review - 2026-10-01

## Current state

The system now supports a complete deterministic Evidence -> Signal path.

## What is working

- Strategy and account evidence remain canonical provenance.
- Signals represent time-bound commercial events rather than general account context.
- Signal-event identity is separate from evaluation identity.
- Re-evaluating the same event does not create duplicate canonical signals.
- Negative and inconclusive evaluations are preserved.
- Demo-time semantics remain deterministic through `demo_as_of`.

## Architecture boundary

M1B.1 intentionally does not include:

- ICP scoring
- account-state snapshots
- decisions
- policy
- actions
- outcomes
- AI / Jev
- external providers

## Next

M1B.2 will derive account state from strategy, evidence, and signal evaluations.

The next engineering question is:

> Given what we know about an account and what has changed, what is its current GTM state?

The state layer will preserve explicit UNKNOWN and INCONCLUSIVE outcomes rather than forcing classifications where evidence is insufficient.
